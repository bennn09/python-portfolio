# W08 Mini Weather Dashboard
## 作品說明
這個作品是一個自動化天氣數據分析與視覺化儀表板。利用 Python向Open-Meteo API取得未來兩天的天氣預報
## 資料來源
Open-Meteo Forecast API
## 使用技術
Python / requests / HTTP GET / JSON
Pandas / DataFrame / 資料統計
Matplotlib / 時間序列視覺化
## 分析內容
1.初始化和API擷取數據
2.資料轉為 DataFrame和時間優化
3.數據統計(計算計算平均溫度、最高溫度與最低溫度/平均降雨機率與最高降雨機率。
)
4.生成逐時溫度變化圖與逐時降雨機率變化圖。

## 本週學習重點
API(擷取)+JSON → 用pandas-DataFrame將資料表格化(轉化) → 統計分析→ 圖表視覺化(呈現)
