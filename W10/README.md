# 第十週 Student Score Explorer
使用 Python、Pandas 與 Streamlit 製作的互動式成績分析 App。使用者可輸入姓名關鍵字、選擇班級與科目、設定高低分門檻，查看符合條件的學生資料、人數與平均分數。
### 使用技術
Python / Pandas / Streamlit
### 專案資料夾結構
W10_Interactive_Data_App/
├── main.py
└── README.md

### 執行環境
$ pip install streamlit pandas
$ streamlit run main.py
## 資料來源
程式內建模擬成績資料共 12 筆
### 學習重點
1. 建立 Streamlit 互動式介面
2. 使用者輸入值與 Python 變數
3. 使用條件判斷控制資料分析
4. 使用 Pandas 篩選 DataFrame
5. 根據條件動態產生分析結果
