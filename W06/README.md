# 第6周學習紀錄
## 1.我的研究問題
- 哪一個科目分數最高
- 數值隨時間如何變化
- 兩個數值之間的關係為何

## 2.Chart01 各科成績比較圖/長條圖
#### 為何選擇它：
因為長條圖能最快看出各科分數差異
#### 觀察到什麼:
國文成績較其他兩高

## 3.Chart02 每日氣溫表/折線圖
### (1)為何選擇它：折線圖能看出某時間內的趨勢變化
### (2)觀察到什麼:趨勢先升再降再升

## 4. 我的結論(圖表中可知和不知)
## Chart01
### 支持：
可以知道最高/最低分數的科目
### 限制：
不能知道各科確切的分數

## Chart02
### 支持：
可以知道時間內的氣溫變化
### 限制：
無法得知在 2 到 3 之間的中間過程是否有發生過劇烈的暴起暴落

## 5.Reflection
今天我發現，圖表不只可以將數據分析化，還可以讓讀者快速識別趨勢與規律，並輕鬆進行對比與比較

我原本以為圖表只能用exsel製作，現在我知道能利用Python做出簡而易懂的圖表，讓讀者更清楚了解我想表達的資訊。

且使用者會依不同需求選擇不同類型的圖表，例如:
#### 長條圖：
不同類別之間，誰比較高/低
#### 折線圖：
觀察連續變化/趨勢變化
#### 散佈圖：
兩個數值之間，是否呈現某種關係/關聯性？

我最滿意的圖表是散佈圖，因為它可以很直接地觀察兩個變數的相關性。

我遇到的問題是預期為中文字的地方是文方框，沒有我想要的科目名稱，所以我利用這段程式碼設定中文字型：
plt.rcParams["font.sans-serif"] = ["Microsoft JhengHei"] 
plt.rcParams["axes.unicode_minus"] = False
